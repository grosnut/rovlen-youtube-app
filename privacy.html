개인정보처리방침

시행일: 2026-11-25

1. 적용 대상

이 방침은 개인용 도구 'rovlen 업로드'(이하 '앱')에 적용됩니다. 앱은 운영자 본인이 소유한 유튜브 채널을 관리하는 데만 쓰입니다.

2. 접근하는 정보

운영자가 Google 계정으로 허용한 범위 안에서 YouTube Data API와 YouTube Analytics API를 통해 운영자 본인 채널의 정보(채널·영상 목록, 조회수 등 통계)를 읽습니다.

3. 이용 목적

채널 운영 현황을 정리하고 확인하는 데만 씁니다. 광고, 판매, 다른 목적에는 쓰지 않습니다.

4. 보관과 제3자 제공

받은 정보와 인증 정보는 운영자의 컴퓨터에만 저장합니다. 제3자에게 팔거나 넘기지 않습니다.

5. Google API 정보 사용

앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 옮기는 방식은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.

6. 접근 권한 철회

사용자는 Google 계정의 서드파티 앱 권한 페이지에서 언제든 앱의 접근 권한을 철회할 수 있습니다.

7. 문의

문의는 이 페이지를 올린 GitHub 저장소의 Issues로 받습니다.
